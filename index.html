☁️Sincronização entre aparelhos desligada

          

            Opcional. Com uma conta gratuita do Supabase, o app sincroniza celular e notebook e guarda seus arquivos na nuvem.
            O conteúdo é criptografado neste aparelho antes de subir — o servidor só vê texto embaralhado.
            O passo a passo está no arquivo README que veio junto com o app.
